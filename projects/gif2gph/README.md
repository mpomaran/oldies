# GIF2GPH

A DOS tool for turning 320×200 GIFs into GPH files for the demo code. [GIF2GPH.C](GIF2GPH.C) looks up each pixel in the GIF palette and converts it to a grayscale value. It uses EOS to read the GIF.

The original source carries the `Sarin/!ArisE!` handle and marks the tool as public domain.
