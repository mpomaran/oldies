# ANIMPART

[Watch the DOSBox-X run](animpart-dosbox.mp4). It opens with “MSG TO: INSECT”, then switches scenes on its own while the tracker music keeps playing. A key exits when the demo asks for one.

This is a continuous 38-second capture of `EFFECTS/ANIMPART.EXE` from `HADES.ZIP`, with `MUSIC.MOD` from the backup. The clip runs through the end of the graphics and keeps the DOSBox-X capture's original frame timing. It includes the emulator's stereo audio.
