# Fractal terrain explorer

Win32 GDI terrain demo with randomized height fields, a rectangular selection and a fractal-dimension command. The recursive height-field generator is in `makeTerrain.cpp`.

## Archive notes

Recovered from the April 2002 backup. The original About dialog resource credits K. K. Zdeb and M. Pomarański. See [fract01.rc](fract01.rc#L114).
The source uses the original Visual C++ project format where available. A current toolchain may require porting.
See the [archive index](../../README.md) for curator and profile links.

## Run observed

The original 32-bit Windows release executable opened under Windows and drew a terrain map.
