# MAIN.EXE

[Watch the 35-second DOSBox-X run](main-dosbox.mp4). It starts with the particle effect and cycles through the messages and title cards before returning to text mode.

The copy of `12.XM` in `HADES.ZIP` ends partway through sample 11. For this run, the missing samples were restored from the matching MOD of [Noise Gate by Dennis / Vipers](https://demozoo.org/music/163748/). The XM patterns are from the backup. The clip has stereo audio from the emulator and keeps the original capture timing.
