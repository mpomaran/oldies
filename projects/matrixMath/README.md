# Matrix math

2002 C++ 3D math experiment with `Matrix4`, vector operations, overloaded arithmetic and a test driver. Start with `math.matrix.h` and `test.cpp`.

## Archive notes

Recovered from the April 2002 backup. Michał Pomarański is credited in [`math.matrix.h`](math.matrix.h).
The source uses the original Visual C++ project format where available. A current toolchain may require porting.
