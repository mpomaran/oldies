# Study archive

Catalog of subjects with selected source artifacts. The study backup also contains reference material, documents and installers.

- [ANG](ANG/) — English-language coursework and writing exercises.
- [arko](arko/) — Computer architecture, assembly-language instruction, and MIPS and SPARC material.
- [eliu](eliu/) — Electronic circuits, including diode and transistor SPICE netlists.
- [fgk](fgk/) — Computer graphics coursework with a fractal-terrain project folder.
- [GFX](GFX/) — Graphics used in historical project documentation, including diagrams for a modified Dijkstra algorithm.
- [GKOM](GKOM/) — Archived coursework package under the GKOM label.
- [MPRD](MPRD/) — Coursework files including a report on pseudorandom numbers.
- [POTC](POTC/) — Coursework collected under the POTC label, with several successive archive files.
- [PROC](PROC/) — Project documentation for a comment converter, a household budget application, and a modified Dijkstra algorithm.
- [PROO](PROO/) — Object-oriented coursework material covering a matrix program and an iterated function system.
- [PROS](PROS/) — Design material for a directory-structure simulator.
- [PSS](PSS/) — Collected exercise and lecture packages under the PSS label.
- [ptkom](ptkom/) — Networking coursework, including a Java Ethernet simulation artifact.
- [PZD](PZD/) — Course notes on nutrition and related health topics.
- [sop](sop/) — Operating-systems labs involving UNIX processes, signals, FIFOs and IPC.
- [ucyf](ucyf/) — Digital logic material, including an alarm project and PLA versions.
- [zbd](zbd/) — Database course collection with SQL Server lab and exercise material.
