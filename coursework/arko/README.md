# arko

Computer architecture, assembly-language instruction, and MIPS and SPARC material.

From a mixed-origin study backup. Authorship is unspecified unless a surviving credit identifies it.

The local assembly-course collection includes `asmwc.c` and `CZASERL.COM`, credited to Grzegorz Złotowicz.
Both call DOS `INT 21h`, function `2Ch`, to read the time. The COM example returns the hour in the DOS exit
status. A local DOSBox-X run confirmed a return code in the range 0–23.
